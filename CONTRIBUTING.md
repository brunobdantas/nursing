# Contribuindo

## Fluxo

1. Abra ou associe uma issue.
2. Crie uma branch curta a partir de `main`.
3. Faça alterações pequenas e rastreáveis.
4. Abra Pull Request usando o template do repositório.
5. Aguarde os checks obrigatórios.

## Regras para código clínico

Alterações em fórmulas, unidades, arredondamentos, eligibility `calculation_ready` ou regras de administração exigem testes e revisão explícita. Nenhuma lógica clínica pode depender de saída de IA generativa.
