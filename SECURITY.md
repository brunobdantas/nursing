# Security Policy

Este projeto contém componentes de software para apoio à administração de medicamentos.
Relatos de vulnerabilidades ou comportamentos que possam afetar segurança clínica devem ser tratados como prioridade alta.

## Regras

- Nunca incluir dados identificáveis de pacientes em issues, PRs, logs ou screenshots.
- Falhas envolvendo cálculo, unidades, concentração, apresentação ou proveniência devem ser sinalizadas explicitamente como potencial impacto clínico.
- O Calculation Core deve permanecer determinístico e coberto por testes.
- Dependências são monitoradas via Dependabot.
